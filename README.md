# Tetris · 单文件俄罗斯方块

一个 HTML 文件就是一个完整的俄罗斯方块：双击打开即玩，不需要服务器、不需要构建、不联网、不加载任何外部资源（没有 CDN、没有字体、没有图片）。

## 玩法

| 按键 | 作用 |
| --- | --- |
| `←` `→` | 左右移动（可长按） |
| `↓` | 软降（每格 +1 分，重力提速 12 倍） |
| `空格` | 硬降（每格 +2 分）并立即锁定 |
| `↑` / `X` | 顺时针旋转 |
| `Z` | 逆时针旋转 |
| `C` | 暂存 / 取出（每块一次） |
| `P` | 暂停 / 继续 |
| `R` | 重开一局 |

手机上会显示触屏按钮；窗口失焦会自动暂停。

## 特性

- 标准七袋随机（7-bag），不会连续憋同一块
- 幽灵落点、下一块预览、暂存槽
- 落地缓冲（约 0.5 秒内还能微调），锁定前移到位可重置缓冲
- 消行粒子、命中反馈、WebAudio 合成音效（可一键静音）
- 等级随消行提升，下落速度逐级加快（每格 800ms → 最快 45ms）
- 计分：消 1/2/3/4 行 = 100/300/500/800 × 当前等级
- 最高分存在 localStorage，刷新不丢
- 自适应窄屏，按 devicePixelRatio 渲染，画面不糊

## 实现说明

- 纯原生 JavaScript（ES5 语法风格）+ Canvas 2D，无任何依赖
- 每种方块用四张旋转态表描述，旋转受阻时依次尝试 8 个推回位移（简化版墙踢，不是完整 SRS 表）
- 棋盘 10×20，额外保留 4 行台面外区域，允许方块从可视区上方生成
- 消行时按行号自上而下收集再删除，避免删下面的行导致上面的行号错位
- 源文件约 820 行，含内联 CSS 与 JS

## 运行

```text
直接双击 tetris.html
```

或者：

```bash
python -m http.server 8000      # 然后访问 http://localhost:8000/tetris.html
```

## 测试

核心规则经过 193 项断言回归：墙与地板的临界位置、单行/双行/四行同消、满盘判负、暂存换回、软降计分、重力速率与预期节拍比对、暂停与失焦、触屏按钮映射，以及 HTML 与 JS 的 id 契约。测试脚本未随仓库提供（它依赖一套本地 DOM 桩）。
